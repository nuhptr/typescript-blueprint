# Flexible Unions

Modul ini membahas **Union Types** dan **Literal Types** untuk membatasi variabel agar hanya menerima beberapa kemungkinan tipe atau nilai tertentu.

## Materi yang Dibahas

1. **Union Types (`|`)** — Mengizinkan satu variabel, properti, atau elemen array memiliki lebih dari satu tipe (misalnya `string | number`).
2. **Union pada Object & Array** — Menggabungkan beberapa tipe objek atau array campuran bertipe aman.
3. **Literal Types** — Membatasi nilai pada literal spesifik seperti `"red" | "blue" | "green"`, `1 | 2 | 3`, atau `true`.

## Menjalankan Kode dengan Bun

```bash
bun app/flexible-unions/index.ts
```
