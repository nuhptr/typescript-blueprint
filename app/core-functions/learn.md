# Core Functions

Modul ini membahas cara memberi tipe pada fungsi di TypeScript, mulai dari parameter, nilai default, nilai kembalian (_return_), `void`, hingga `never`.

## Materi yang Dibahas

1. **Parameter Annotations** — Memberi tipe pada setiap parameter regular function maupun arrow function.
2. **Default Parameters** — Memberi nilai bawaan pada parameter jika argumen tidak dikirim.
3. **Return Annotations** — Menentukan tipe nilai yang dikembalikan oleh fungsi.
4. **Void (`void`)** — Menandakan fungsi tidak mengembalikan nilai apa pun.
5. **Never (`never`)** — Menandakan fungsi tidak pernah selesai secara normal (misalnya selalu `throw Error` atau infinite loop).
