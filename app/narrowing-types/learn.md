# Narrowing Types

Modul ini membahas teknik **Type Narrowing** untuk mempersempit tipe union menjadi tipe yang lebih spesifik sebelum mengakses properti atau method tertentu.

## Materi yang Dibahas

1. **`typeof` Type Guards** — Membedakan tipe primitif (`string`, `number`, `boolean`, dll.).
2. **`instanceof` Operator** — Membedakan instance dari class yang berbeda.
3. **Intersection Types (`&`)** — Menggabungkan beberapa tipe agar seluruh properti tersedia secara aman.

## Menjalankan Kode dengan Bun

```bash
bun app/narrowing-types/index.ts
```
