# Data Arrays

Modul ini membahas cara mendeklarasikan dan menggunakan tipe array di TypeScript.

## Materi yang Dibahas

1. **Bracket Notation (`T[]`)** — Sintaks paling umum untuk mendeklarasikan array bertipe (`number[]`, `string[]`).
2. **Generic Array Syntax (`Array<T>`)** — Sintaks alternatif yang ekuivalen dengan `T[]`.
3. **Multidimensional Arrays (`T[][]`, `T[][][]`)** — Array bersarang (matriks / grid).

## Menjalankan Kode dengan Bun

```bash
bun app/data-arrays/index.ts
```
