# Hierarchy Classes

Modul ini membahas pemrograman berorientasi objek (OOP) dengan **Class** di TypeScript.

## Materi yang Dibahas

1. **Class Annotations & Class Fields** — Menentukan tipe properti dan nilai default pada class.
2. **Readonly Properties** — Properti class yang hanya bisa di-set di constructor.
3. **Access Modifiers (`public`, `private`, `protected`)** — Mengatur visibilitas properti dan method.
4. **Parameter Properties Shorthand** — Deklarasi sekaligus inisialisasi properti langsung di parameter constructor.
5. **Getters & Setters** — Mengakses dan memvalidasi perubahan properti privat dengan `get` dan `set`.
6. **Inheritance (`extends`)** — Pewarisan class dan akses properti `protected` di subclass.

## Menjalankan Kode dengan Bun

bun app/hierarchy-classes/index.ts
