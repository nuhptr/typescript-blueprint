# Essential Objects

Modul ini membahas cara mendefinisikan struktur objek di TypeScript secara aman dan dapat digunakan ulang.

## Materi yang Dibahas

1. **Object Types** — Menentukan bentuk properti objek pada variabel maupun return type fungsi.
2. **Type Aliases (`type`)** — Membuat nama tipe yang dapat dipakai ulang.
3. **Optional Properties (`?`)** — Menandai properti yang boleh ada atau tidak ada.
4. **Readonly Properties (`readonly`)** — Mencegah perubahan nilai properti setelah diinisialisasi.
5. **Intersection Types (`&`)** — Menggabungkan beberapa tipe objek menjadi satu tipe baru.

## Menjalankan Kode dengan Bun

```bash
bun app/essential-objects/index.ts
```
