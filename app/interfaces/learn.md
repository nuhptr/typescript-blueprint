# Interfaces

Modul ini membahas **Interface** sebagai kontrak struktur data untuk objek, fungsi, method, class, pewarisan interface, dan *declaration merging*.

## Materi yang Dibahas

1. **Object Interface** — Mendefinisikan kontrak properti objek (termasuk `readonly` & optional `?`).
2. **Interface for Functions** — Mendefinisikan signature fungsi.
3. **Interface with Methods** — Menyertakan definisi method di dalam interface.
4. **Extending Interfaces (`extends`)** — Mewarisi properti dan method dari interface lain.
5. **Interface for Classes (`implements`)** — Memastikan class memenuhi kontrak interface.
6. **Declaration Merging** — Mendeklarasikan ulang interface dengan nama yang sama untuk menambah properti/method.

## Menjalankan Kode dengan Bun

```bash
bun app/interfaces/index.ts
```
